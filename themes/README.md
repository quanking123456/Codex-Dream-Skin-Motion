# Downloadable themes

This directory contains optional themes that can be copied into the Windows
Codex Dream Skin saved-theme library. They are not installed automatically.

## Included themes

- `Wlop`: dynamic background using `Wlop.mp4`, with `art.jpg` as its poster and
  fallback image.
- `R-c`: static background using `background.jpg`.
- `Wlof-Example`: dynamic background using `Wlof示例.mp4`, with `art.jpg` as
  its poster and fallback image.

## Install on Windows

1. Install this Motion fork and exit Codex Dream Skin.
2. Copy the complete `Wlop`, `R-c`, or `Wlof-Example` directory into
   `%LOCALAPPDATA%\CodexDreamSkin\themes\`.
3. Start the Dream Skin tray, open **Saved themes**, and select the theme.

Keep every file together in its theme directory. The dynamic theme is installed
by copying the directory because the ZIP/community importer intentionally keeps
its image-only security contract.

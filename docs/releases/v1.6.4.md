# Codex Dream Skin Motion v1.6.4

This is the first complete public release of Codex Dream Skin Motion. It adds
stable local MP4 backgrounds on Windows and includes the downloadable `Wlop`
dynamic theme and `R-c` static theme.

The macOS lane builds and runs the native XCTest bundle directly. On GitHub's
current ARM macOS hosts, XCTest can print a complete successful report and
still return status 1; the release now accepts that status only when the final
all-tests success marker, a nonzero test count, and zero failures are all
present, while any missing or failed result remains fatal. Legacy version
constants in the macOS test suite are now derived from `VERSION` as well.

The earlier public `v1.6.0` through `v1.6.3` tags are retained as unpublished
build attempts; none of those tags is moved or overwritten.

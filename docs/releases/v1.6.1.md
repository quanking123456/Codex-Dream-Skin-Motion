# Codex Dream Skin Motion v1.6.1

This release contains the Windows MP4 background feature and the downloadable
`Wlop` and `R-c` themes introduced for the Motion fork.

It also restores the reviewed Gothic Void Crusade preset metadata byte-for-byte
so the pinned release-asset integrity checks pass. The public `v1.6.0` tag is
retained as an unpublished build attempt and is not moved or overwritten.

This tag was superseded by `v1.6.2` after GitHub's macOS 26 ARM runner exposed
a SwiftPM empty-suite exit-code incompatibility before DMG assembly began.

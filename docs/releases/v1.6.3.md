# Codex Dream Skin Motion v1.6.3

This is the first complete public release of Codex Dream Skin Motion. It adds
stable local MP4 backgrounds on Windows and includes the downloadable `Wlop`
dynamic theme and `R-c` static theme.

For reliable macOS packaging, SwiftPM now builds the native XCTest bundle and
Apple's `xcrun xctest` executes it directly. This preserves real test-failure
exit codes while avoiding an erroneous SwiftPM test-driver status observed on
GitHub's current macOS runners. The unsigned DMG and Windows Setup are built
from the same tagged commit.

The earlier public `v1.6.0`, `v1.6.1`, and `v1.6.2` tags are retained as
unpublished build attempts; none of those tags is moved or overwritten.

# Codex Dream Skin Motion v1.6.0

This release introduces stable local MP4 backgrounds on Windows while keeping
the official Codex package untouched.

## Highlights

- Select an MP4 from the Windows tray and play it muted, automatically, and on
  a loop behind the native Codex interface.
- Keep a still image as the poster and failure fallback.
- Save and switch video themes without repeated renderer mounts or periodic
  poster flashes.
- Prefer CDP file-handle delivery, with a tokenized loopback-only Range server
  as a bounded fallback.
- Download the optional `Wlop` dynamic theme and `R-c` static theme from the
  repository's `themes/` directory.

The community ZIP importer remains image-only. To use the included dynamic
theme, copy its complete directory into
`%LOCALAPPDATA%\CodexDreamSkin\themes\` and select it from the tray.

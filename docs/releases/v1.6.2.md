# Codex Dream Skin Motion v1.6.2

This is the first complete public release of Codex Dream Skin Motion. It adds
stable local MP4 backgrounds on Windows and includes the downloadable `Wlop`
dynamic theme and `R-c` static theme.

The release also keeps the reviewed bundled preset metadata intact, runs only
the existing XCTest suite, and pins release packaging to GitHub's stable macOS
15 image. This avoids a macOS 26 SwiftPM exit-code incompatibility and lets the
unsigned DMG and Windows Setup artifacts finish publishing.

The earlier public `v1.6.0` and `v1.6.1` tags are retained as unpublished build
attempts; neither tag is moved or overwritten.

# Codex Dream Skin Motion v1.6.5

## 修复 / Fixes

- 适配 Codex 26.928.3736.0：仅隐藏顶部渐变装饰，不再误隐藏会话与输入框的父容器。
- 修复保留隐藏首页时，对话页背景变为不透明黑色的问题。
- 适配没有 `#root` ID 的新版应用容器，确保聊天内容与输入框位于动态视频背景上方。
- 增加双端生成样式、顶部渐变容器和视频层级的回归检查。

Windows 本机已验证聊天内容、输入框及 MP4 持续播放。macOS 使用同步的共享样式，并由发布流程执行原生测试与 DMG 构建；没有宣称对应版本的 macOS 实机验收。

The Windows and macOS packages share the updated selector/CSS contract.
Existing saved themes remain supported. This release does not modify the
official Codex application or include private configuration or local backups.

## 下载 / Downloads

- Windows: `CodexDreamSkin-Setup-v1.6.5.exe`
- macOS: `CodexDreamSkin-v1.6.5.dmg`
